# 局域网文件共享桌面软件

Windows 优先的 Electron + TypeScript 局域网点对点文件共享软件。每台电脑既是桌面客户端，也是只读文件服务端。

## 功能

- 本机软件文件库：创建文件夹、上传文件、取消共享、重新共享。
- 局域网发现：通过 UDP 广播发现同一网段内运行本软件的电脑。
- 只读远程访问：远程用户只能预览和下载，不能上传、编辑、删除或取消共享。
- 文件预览：支持图片、PDF、文本、音频、视频。
- 断点下载：HTTP Range 下载，失败后可重试并复用 `.part` 临时文件。
- 设置：设备名称、本机文件库路径、服务端口、发现端口、开机启动。

## 运行

```bash
npm install
npm run dev
```

生产模式本地运行：

```bash
npm run build
npm start
```

## 局域网说明

- 文件只保存在上传者电脑上，上传者离线后其他电脑不能继续预览或下载。
- 第一版默认信任同一局域网内运行本软件的用户，不包含账号、密码、设备审批或传输加密。
- Windows 首次运行可能弹出防火墙提示，需要允许局域网访问，否则其他电脑无法发现或下载。
